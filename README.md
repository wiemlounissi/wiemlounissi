## 🚀 Featured Project

### SIGNAL — Segmentation, Insurance Generation, Analytics and Learning

My Master's thesis project developed during my internship at **Bridges S.A.**, focused on applying Data Science and Machine Learning to health insurance data.

The project combines:

* 📊 Statistical analysis of insurance portfolios
* 🔎 Feature engineering and exploratory analysis
* 🧩 PCA / UMAP dimensionality reduction
* 🎯 K-Means & hierarchical clustering
* 🤖 Machine Learning predictive models
* 📈 Gradient Boosting & regularized regression
* 🎲 Monte Carlo simulation
* 📐 Risk and uncertainty analysis
* 🧮 Predictive modeling for insurance costs
* 📊 Decision-support indicators

**Objective:** build a data-driven system capable of identifying portfolio profiles, predicting annual healthcare costs and supporting insurance decision-making.
